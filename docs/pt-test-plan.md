# Packet Tracer test plan

Generated by `ciscoaudit validate --pt-plan` from `scenarios/scenarios.yaml`; do not edit by hand.

Run each test on the hardened network (after pasting the rendered configurations, see `docs/packet-tracer-build.md`) and record the outcome in `evidence/packet-tracer/results.csv`. The **Simulator predicts** column is what the configuration files imply; whether Packet Tracer agrees is exactly what these tests find out. A disagreement is a finding, not an error in this document: record it.

Result vocabulary for the CSV: `succeeded` (the request worked), `blocked` (it failed or timed out), `not-supported` (Packet Tracer rejected the command or lacks the feature), `not-run`.
